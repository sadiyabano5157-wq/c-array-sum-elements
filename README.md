# C Array Sum Program

This project is a simple C program.

It takes 5 numbers from the user and stores them in an array.

Then it prints all array elements and calculates the total sum.

## Features

* Array input
* Print array elements
* Calculate total sum
* Display final result

## Language

C Programming
